# لوحة الرفع الاحترافية (Upload Panel)

انسخ مجلد `src` فوق `src` بتاع مشروع UIP-React (الملفات نفس مساراتها).

جديد:
- src/lib/transfers.js  — مدير الرفع (حالة كل ملف: انتظار / جاري / تم / فشل)
- src/components/UploadProgress.jsx — اللوحة نفسها

متعدّل:
- src/lib/driveApi.js — drive.upload بيسجّل كل رفع تلقائي (شريط، سرعة، إلغاء، إعادة محاولة)
- src/desktop/DesktopOS.jsx — تركيب اللوحة + السحب والإفلات على سطح المكتب بقى بيعرض الدفعة كلها
- src/pages/student/StudentMyPC.jsx — الـ Explorer بيسجّل الملفات في اللوحة، واتشال صندوق الرفع القديم الصغير
- src/styles/css/my-pc.css — ستايل اللوحة (.up-*)

اللوحة بتعرض: شريط تقدّم كلي + النسبة + السرعة + الوقت المتبقي، وصف لكل ملف (أيقونة نوعه، الحجم المرفوع من الكلي،
شريط خاص، زر إلغاء)، "إلغاء الكل"، "إعادة" للي فشل، تصغير، وبتختفي لوحدها بعد ٦ ثواني من انتهاء الرفع بنجاح.
